Local processing & privacy verification

Core inspect workflow: the browser parses JSON with a same-origin Web Worker. The product does not intentionally upload the inspected JSON to an API, remote AI service or analytics endpoint. Source is held in browser memory for the active document. This describes the present code, not a promise against compromised hosting or browser extensions.

What happens to your data?

  • Pasting, opening files, searching, drift analysis and report generation operate locally in the browser.
  • Static HTML, JavaScript and CSS are downloaded from the site hosting this app when first loaded. This is not the same as sending your JSON content.
  • Input files are not intentionally written to localStorage, IndexedDB, Cache Storage or cookies by the application.
  • Clipboard access occurs only after choosing a copy action. Downloads occur only after choosing an export action. Their contents may be accessible to local software and users of your device.
  • Default report exports omit user JSON, field names, pointers, filenames and raw evidence. Aggregate statistics may reveal structural patterns.
  • If you explicitly enable detailed evidence, it can contain confidential field names, paths and raw snippets. A separate preview and confirmation are required.

How to verify

  1. Open Developer Tools → Network, enable Preserve log, and paste a synthetic marker (never a real secret).
  2. Inspect JSON, run Schema Drift and generate a default report. Look for outgoing requests and inspect their URLs and bodies.
  3. Open Application / Storage and check cookies, localStorage, IndexedDB and Cache Storage before and after.
  4. Review the reproducible Chromium test in tests/e2e/product_v1_privacy_report_playwright.py.

Tests measure behavior of the checked-in build on a particular browser and cannot guarantee properties of compromised servers, modifications made by extensions, or a future release.

Limits and independent checks

The current parser input cap is 2 MiB. A valid JSON payload is not proof of correct business data. The syntax and deterministic-risk checks cover only specific cases; Schema Drift is observational rather than a validated API contract.

Do not include proprietary or sensitive source in issue reports unless your organization permits it. Prefer synthetic reproductions.
